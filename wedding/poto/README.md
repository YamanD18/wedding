Taruh foto-foto di folder ini dengan nama file berikut (format jpg/png):

- cover.jpg      -> foto di cover (bagian atas, akan terpotong otomatis setengah)
- foto2.jpg      -> foto lingkaran di hero page (setelah undangan dibuka)
- story.jpg      -> foto kotak di bagian "Perjalanan Cerita Kami"
- gallery1.jpg ... gallery8.jpg  -> 8 foto galeri
- closing.jpg    -> foto lingkaran penutup

Jika sebuah file belum ada, halaman tetap tampil rapi (bagian foto akan
otomatis disembunyikan, bukan menampilkan gambar rusak).
